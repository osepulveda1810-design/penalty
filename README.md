# Penales 3D

## Publicar en GitHub Pages

1. Descomprime este archivo en tu computador.
2. Sube `index.html`, la carpeta `assets/` y este README a la raíz de tu repositorio de GitHub.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama principal y la carpeta **/(root)**.
5. Guarda y espera a que GitHub Pages publique el sitio.

Conserva esta estructura:

```text
index.html
assets/personajes.webp
assets/cr7-kick.webp
```

El juego carga Three.js desde un CDN, por lo que necesita conexión a internet. La animación de cinco poses está conectada para Cristiano Ronaldo; los otros personajes conservan sus sprites estáticos.
